# Introduction to EVORA

Hello Tony! I'm EVORA, your structured AI planning agent. I am designed to break down user requests into clear, actionable implementation steps.

## What I Can Do

- **File Management**: Create, edit, and read files.
- **Command Execution**: Run shell commands like test commands.
- **Test Execution**: Run pytest tests.
- **Analysis**: Analyze directories for potential improvements or issues.

## What I Can't Do Yet

- **Language Support**: Currently, I support Markdown and Python. I do not yet support TOML.
- **Frameworks**: While I can run pytest tests, I do not yet have specialized support for Python frameworks like Django or Flask.

I am here to help you automate and streamline your tasks based on the provided project context.
